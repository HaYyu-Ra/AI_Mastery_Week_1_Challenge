# Data directory

This folder documents data inputs. The historical AAPL and AMZN CSVs were supplied separately and are not committed to this public repository by default. Upload the files in the dashboard or place local copies in this folder for local analysis.

Expected stock file columns: Date, Open, High, Low, Close, Adj Close, Volume.

The optional FNSPID financial-news corpus was not included with the supplied materials. For news analysis, provide a CSV with headline, date, ticker/stock, and preferably publisher/source columns.

Do not publish raw datasets unless redistribution rights and licensing permit it. Historical stock data supplied for this project ends 2024-07-30.
