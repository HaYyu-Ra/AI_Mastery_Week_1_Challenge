# 10 Academy AI Mastery — Week 1 Challenge Brief

## Project purpose
This repository implements the Week 1 financial-news and stock-price analytics challenge using historical AAPL and AMZN data.

## Task 1 — Data Engineering and Exploratory Data Analysis
- Set up a reproducible Python environment and Git/GitHub workflow.
- Load, validate, clean, and document the stock-price and financial-news data.
- Calculate descriptive statistics and explore missing values, duplicate records, distributions, and outliers.
- Analyze news publishers and publication-time patterns.
- Apply NLP to headlines, including sentiment analysis and topic exploration.

## Task 2 — Financial Quantitative Analysis
- Calculate daily stock returns and relevant performance measures.
- Compute technical indicators, including moving averages, RSI, and MACD.
- Examine volatility, drawdowns, and historical financial performance.
- Visualize price trends, returns, and indicators.

## Task 3 — News and Stock Correlation
- Align news articles and stock-price observations by ticker and date.
- Aggregate headline sentiment to daily observations.
- Compare daily sentiment with stock returns.
- Calculate Pearson and Spearman correlations and statistical significance.
- Interpret findings cautiously; association does not establish causation.

## Task 4 — Reporting and Dashboard
- Present interactive financial analytics and visualizations.
- Summarize methodology, results, limitations, and investment-related observations.
- Provide reproducible documentation and instructions for running the project.

## Data availability note
The materials supplied for this implementation included AAPL and AMZN historical-price CSV files. The FNSPID financial-news dataset was not supplied. Therefore, the repository includes a news-processing workflow that accepts the actual news CSV, but publisher-level findings, headline sentiment results, topic outputs, and news/return correlation results remain pending until that dataset is provided. No fabricated news observations or statistics are reported.
